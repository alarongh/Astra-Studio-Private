# Astra Studio Release 3.15 — portable Windows

## Запуск

1. Полностью распакуйте ZIP в обычную доступную для записи папку.
2. Откройте папку `Astra Studio`.
3. Запустите `Astra Studio.exe`.

Не переносите один EXE отдельно: это onedir-сборка, и ей нужна соседняя папка `_internal`. Python и проектная `.venv` для запуска portable-приложения не требуются.

Пользовательские настройки и диагностический лог сохраняются вне папки приложения в локальном профиле Windows. Поэтому замена распакованной папки новой версией не должна удалять настройки пользователя.

## Обновление

В установщике Astra доступна команда проверки обновления приложения. Astra скачивает ZIP только после подтверждения, проверяет версию, размер, SHA-256 и структуру архива, затем закрывается, заменяет portable-папку и запускается снова. Установщик обновления запускается из отдельной рабочей папки, а при ошибке возвращает прежнюю сборку, снова открывает Astra и показывает путь к журналу.

Публичные релизы и feed находятся в репозитории `alarongh/Astra-Studio-Releases`; авторизация GitHub для загрузки не требуется.

## Angel 404

Откройте `Настройки` → `Оформление` и нажмите `Применить профиль Angel 404`. Профиль включает фиолетово-чёрную тему, обои и Minecraft Rus. Шрифт также можно переключать отдельно в разделе `Шрифты`; изменение применяется ко всему тексту приложения и сохраняется после перезапуска.

## Если Windows блокирует запуск

Проверьте SHA-256 ZIP по файлу контрольных сумм из релиза. Если архив получен из доверенного источника и сумма совпадает, распакуйте его заново в локальную папку. Не запускайте EXE прямо из окна архиватора.
